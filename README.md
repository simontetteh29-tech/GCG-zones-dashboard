# GCG Operational Zones Dashboard

Interactive Streamlit dashboard for visualizing operational zones across Ghana districts.

## Features

- Interactive Ghana district map
- Zone-based filtering
- District and region assignment table
- Unassigned district reporting
- Plotly choropleth visualization

## Requirements

- Python 3.10+
- Streamlit
- GeoPandas
- Plotly

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Data Source

GADM Ghana Administrative Boundaries

File used:

```text
gadm41_GHA_2.json.zip
```
